# A2DP Tiny Radio - User Manual

## はじめに (Introduction)

A2DP Tiny Radioをお買い上げいただき、ありがとうございます。本製品は、超小型のFMラジオとBluetooth送信機を組み合わせた革新的なデバイスです。

Thank you for choosing the A2DP Tiny Radio. This device combines a compact FM radio with Bluetooth transmission capabilities.

## 製品の特徴 (Product Features)

### 主な機能
1. **FMラジオ受信** (FM Radio Reception)
   - 周波数範囲: 76.0 - 108.0 MHz
   - 自動チャンネルスキャン
   - Automatic channel scanning
   - プリセット局登録 (10局まで)
   - Preset stations (up to 10)

2. **Bluetooth A2DP送信** (Bluetooth A2DP Transmission)
   - Bluetoothバージョン: 5.0 (JDY-64使用時)
   - プロファイル: A2DP (Advanced Audio Distribution Profile)
   - 通信距離: 約10m (障害物なし)
   - Range: Approximately 10m (unobstructed)

3. **3.5mmイヤホン出力** (3.5mm Earphone Output)
   - ステレオ出力
   - Stereo output
   - FMアンテナとしても機能
   - Also functions as FM antenna

4. **小型ディスプレイ** (Compact Display)
   - 0.91インチ OLED (128x32ピクセル)
   - 周波数、信号強度、接続状態を表示
   - Displays frequency, signal strength, connection status

## セットアップ (Setup)

### 初回起動 (First Power-On)

1. **電源の接続 (Power Connection)**
   ```
   USB電源アダプタ → USB-Cケーブル → 本体
   USB power adapter → USB-C cable → Device
   ```
   - 電源LEDが赤く点灯することを確認
   - Verify power LED illuminates red
   - ディスプレイに起動画面が表示
   - Display shows startup screen

2. **イヤホンの接続 (Connect Earphones)**
   - 3.5mmジャックにイヤホンを接続
   - Connect earphones to 3.5mm jack
   - ⚠️ イヤホンケーブルがFMアンテナとして機能
   - ⚠️ Earphone cable functions as FM antenna
   - イヤホン未接続時は受信感度が低下
   - Reception quality decreases without earphones

3. **初期設定 (Initial Settings)**
   - 工場出荷時は87.5 MHzに設定
   - Factory default: 87.5 MHz
   - お住まいの地域の放送局に合わせて調整
   - Tune to local stations in your area

## 基本操作 (Basic Operations)

### 選局 (Tuning)

#### 手動選局 (Manual Tuning)
1. CH+ボタンを短く押す → 周波数が0.1MHz上がる
2. CH-ボタンを短く押す → 周波数が0.1MHz下がる

Steps:
1. Short press CH+ button → Frequency increases by 0.1MHz
2. Short press CH- button → Frequency decreases by 0.1MHz

#### 自動スキャン (Auto Scan)
1. CH+ボタンを1秒長押し → 上方向にスキャン開始
2. CH-ボタンを1秒長押し → 下方向にスキャン開始
3. 強い電波の局が見つかると自動停止

Steps:
1. Long press CH+ (1 second) → Scan upward
2. Long press CH- (1 second) → Scan downward
3. Automatically stops at strong station

### プリセット登録 (Preset Stations)

#### 登録方法 (How to Save)
1. 登録したい周波数に合わせる
2. Tune to desired frequency
3. MODEボタンを短く押してプリセットモードへ
4. Short press MODE to enter preset mode
5. CH+/CH-でプリセット番号を選択 (1-10)
6. Select preset number (1-10) with CH+/CH-
7. MODEボタンを2秒長押しして保存
8. Long press MODE (2 seconds) to save

#### 呼び出し方法 (How to Recall)
1. MODEボタンでプリセットモードへ
2. Enter preset mode with MODE button
3. CH+/CH-でプリセット番号を選択
4. Select preset number with CH+/CH-
5. MODEボタンを短く押して決定
6. Short press MODE to confirm

### Bluetooth接続 (Bluetooth Connection)

#### ペアリング (Pairing)
1. MODEボタンを2秒長押し
2. Long press MODE button for 2 seconds
3. Bluetooth LEDが点滅開始
4. Bluetooth LED starts flashing
5. スマートフォン/タブレットのBluetooth設定を開く
6. Open Bluetooth settings on phone/tablet
7. デバイス一覧から「FMRadio」を選択
8. Select "FMRadio" from device list
9. 接続完了後、Bluetooth LEDが点灯
10. Bluetooth LED stays lit when connected

#### 再接続 (Reconnecting)
- 一度ペアリングした機器は自動再接続されます
- Previously paired devices reconnect automatically
- 再接続しない場合は、上記ペアリング手順を実施
- If not reconnecting, repeat pairing procedure

#### 接続解除 (Disconnecting)
- スマートフォン側でBluetooth接続を解除
- Disconnect from phone's Bluetooth settings
- または本体の電源をOFF
- Or turn off device power

### 音量調整 (Volume Control)

**イヤホン使用時 (Wired Earphones):**
- 現在のファームウェアでは固定音量
- Current firmware uses fixed volume
- 将来のアップデートで対応予定
- Volume control planned for future update

**Bluetooth使用時 (Bluetooth):**
- 接続先の機器（スマホ等）で音量調整
- Adjust volume on connected device (phone, etc.)
- A2DPプロファイルの音量制御に対応
- Supports A2DP profile volume control

## トラブルシューティング (Troubleshooting)

### 電源が入らない (No Power)
**症状:** 電源LEDが点灯しない
**対処法:**
- USB-Cケーブルの接続を確認
- Check USB-C cable connection
- 別のUSB電源を試す
- Try different USB power source
- ケーブルの断線を確認
- Check cable for damage

### ディスプレイに何も表示されない (Blank Display)
**症状:** 電源は入るがディスプレイが真っ暗
**対処法:**
- 一度電源を抜いて再起動
- Disconnect power and restart
- ディスプレイのコントラスト設定（ファームウェア）
- Check display contrast (firmware setting)
- 修理が必要な場合あり
- May require repair

### FM放送が受信できない (No FM Reception)
**症状:** 雑音のみ、または信号強度が低い
**対処法:**
- ✅ **イヤホンを必ず接続**（アンテナとして必須）
- ✅ **Always connect earphones** (required as antenna)
- 窓際など電波が届きやすい場所で試す
- Try near window or better reception area
- 自動スキャンで強い局を探す
- Use auto-scan to find strong stations
- イヤホンケーブルを伸ばす（アンテナ長確保）
- Extend earphone cable (better antenna length)

### 音が出ない (No Audio)
**症状:** 受信はできるが音が聞こえない

**イヤホン出力の場合:**
- イヤホンプラグの差し込みを確認
- Check earphone plug insertion
- 別のイヤホンで試す
- Try different earphones
- イヤホン自体の故障を確認
- Verify earphones are working

**Bluetooth出力の場合:**
- Bluetooth接続を確認
- Verify Bluetooth connection
- スマホの音量を確認
- Check phone volume
- A2DPプロファイル対応を確認
- Verify A2DP profile support
- 再ペアリングを試す
- Try re-pairing

### Bluetoothが接続できない (Bluetooth Won't Connect)
**症状:** ペアリングできない、または接続が切れる
**対処法:**
- ペアリングモードに入り直す
- Re-enter pairing mode
- スマホのBluetooth設定から古いペアリングを削除
- Delete old pairing from phone settings
- 他のBluetooth機器の電源をOFFにする（干渉防止）
- Turn off other Bluetooth devices (prevent interference)
- 距離を近づける（10m以内）
- Move closer (within 10m)
- 電源を入れ直す
- Restart device

### 電波干渉 (Radio Interference)
**症状:** 雑音が多い、音が途切れる
**対処法:**
- USB電源の質を確認（ノイズの少ない電源を使用）
- Use quality USB power (low noise)
- 電子機器から離す（Wi-Fiルーター、電子レンジ等）
- Move away from electronics (Wi-Fi, microwave, etc.)
- イヤホンケーブルを整える
- Arrange earphone cable properly

### ボタンが反応しない (Buttons Not Responding)
**症状:** ボタンを押しても動作しない
**対処法:**
- 電源を入れ直す
- Restart device
- 強く確実に押す（クリック感があるまで）
- Press firmly (until click is felt)
- ボタン周辺のケースの干渉を確認
- Check for case interference around buttons

## よくある質問 (FAQ)

**Q1: バッテリーは内蔵されていますか？**
**Q1: Does it have a built-in battery?**

A: いいえ、USB電源での動作のみです。モバイルバッテリーと組み合わせることで持ち運べます。

A: No, it requires USB power. Can be used with mobile battery for portability.

**Q2: 海外のFM放送も受信できますか？**
**Q2: Can it receive FM broadcasts from other countries?**

A: 76-108 MHzの範囲であれば受信可能です。ファームウェア設定で周波数範囲を調整できます。

A: Yes, within 76-108 MHz range. Frequency range can be adjusted in firmware settings.

**Q3: 同時に複数のBluetooth機器に接続できますか？**
**Q3: Can it connect to multiple Bluetooth devices simultaneously?**

A: いいえ、1対1の接続のみです。

A: No, only one-to-one connection is supported.

**Q4: イヤホンなしでBluetoothだけ使えますか？**
**Q4: Can I use Bluetooth without earphones?**

A: Bluetooth出力のみの使用は可能ですが、イヤホンケーブルがFMアンテナとして機能するため、受信感度が大幅に低下します。

A: Yes, but reception will be significantly degraded as earphone cable serves as FM antenna.

**Q5: 録音機能はありますか？**
**Q5: Does it have recording capability?**

A: いいえ、現在のバージョンには録音機能はありません。

A: No, current version does not include recording functionality.

**Q6: プリセットはいくつまで登録できますか？**
**Q6: How many presets can I save?**

A: 10局まで登録可能です。

A: Up to 10 preset stations.

**Q7: 電池の寿命はどのくらいですか？**
**Q7: What is the battery life?**

A: 本体にバッテリーは内蔵されていません。5000mAhのモバイルバッテリーで約20時間の連続使用が可能です。

A: No built-in battery. With 5000mAh mobile battery, approximately 20 hours of continuous use.
